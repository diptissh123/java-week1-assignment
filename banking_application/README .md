# Banking Application

## Objective

The Banking Application is a console-based Java application that simulates basic banking operations such as deposit, withdrawal, and balance inquiry.

## Features

- Deposit money
- Withdraw money
- Check account balance
- Exit the application
- Input validation
- Exception handling for invalid input
- Validation for negative amounts
- Validation for insufficient balance

## Technologies Used

- Java
- Core Java
- Object-Oriented Programming (OOP)
- Exception Handling
- Eclipse IDE

**## Steps to Compile and Run**
```

### Using Eclipse IDE

1. Open Eclipse IDE.
2. Open the `BankApplication` project.
3. Open the `Main.java` file.
4. Right-click on `Main.java`.
5. Select **Run As → Java Application**.
6. The Banking Application menu will appear in the console.
7. Select the required operation and enter the requested amount.

### Using Command Line

Navigate to the `src` directory and compile the Java files:

```bash
javac bank_application/*.java
