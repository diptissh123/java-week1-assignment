# Java Week 1 Assignment

## Project Explanation

This repository contains the Java Week 1 assignments completed as part of the Java development training.

The assignment focuses on strengthening Java programming fundamentals through practical console-based applications.

The repository contains three projects:

1. Library Management System
2. Banking Application
3. Java Collections Challenge

These projects demonstrate important Java concepts such as Object-Oriented Programming, collections, exception handling, input validation, class design, and basic application development.

## Projects Included

### 1. Library Management System

A console-based application for managing books in a library.

Main features:

- Add books
- View all books
- Search books by ID or title
- Issue books
- Return books
- Remove books
- Exit the application

### 2. Banking Application

A console-based banking application that performs basic account operations.

Main features:

- Deposit money
- Withdraw money
- Check account balance
- Input validation
- Exception handling
- Exit the application

### 3. Java Collections Challenge

A Java project demonstrating the practical use of different Java Collections Framework classes.

Collections used:

- ArrayList
- HashMap
- Queue

The project demonstrates operations such as adding, removing, updating, searching, and iterating through collection elements.

## Technologies Used

- Java
- JDK 1.8
- Eclipse IDE
- Java Collections Framework
- Object-Oriented Programming
- Exception Handling
