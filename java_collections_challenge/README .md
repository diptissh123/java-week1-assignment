# Java Collections Challenge

## Objective

The Java Collections Challenge demonstrates the use of Java Collections Framework classes to store, manage, search, update, remove, and iterate over data.

## Collections Used

- ArrayList
- HashMap
- Queue

## Features

### ArrayList

- Add elements
- Remove elements
- Update elements
- Search elements
- Iterate through elements

### HashMap

- Add key-value pairs
- Search values using keys
- Update values
- Remove key-value pairs
- Iterate through entries

### Queue

- Add elements to the queue
- Remove elements from the queue
- View the front element
- Iterate through queue elements

## Technologies Used

- Java Collections Framework

## Steps to Compile and Run

### Using Eclipse IDE

1. Open Eclipse IDE.
2. Open the Java Collections Challenge project.
3. Open the `Main.java` file.
4. Right-click on `Main.java`.
5. Select **Run As → Java Application**.
6. View the output in the Eclipse console.

### Using Command Line

Navigate to the `src` directory.

Compile the Java files:

```bash
javac collection_challenge/*.java
